# Celebration & Event Planner AI 🚀
Built for PromptWars Virtual (Hack2skill)

## Overview
A GenAI-powered planning assistant built using Google AI Studio to help users organize weddings, birthdays, and community events with instant budgets, timelines, vendor checklists, and personalized theme ideas.

## Features
- **Localized Budget Allocation:** Calculates and breaks down costs (venue, food, décor) in INR.
- **Milestone Timelines:** Generates a custom countdown schedule leading up to the event date.
- **Vendor Action Plan:** Actionable hiring milestones.
- **Creative Personalization:** Unique theme and decor suggestions.

## Tech Stack
- Google AI Studio / Google Gemini LLM API
- Prompt Engineering & System Instructions
